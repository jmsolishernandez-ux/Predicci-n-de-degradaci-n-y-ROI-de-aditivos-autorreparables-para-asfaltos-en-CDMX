# Predicci-n-de-degradaci-n-y-ROI-de-aditivos-autorreparables-para-asfaltos-en-CDMX
Modelo de predicción de degradación de pavimentos y ROI de aditivos autorreparables para CDMX, Mexico
Este repositorio contiene un modelo de Machine Learning diseñado para predecir el deterioro de pavimentos asfálticos y optimizar la toma de decisiones presupuestales. El proyecto integra variables climáticas y operativas críticas para comparar el desempeño del asfalto convencional frente a tecnologías innovadoras de auto-reparación (Aditivo Paflec).
Las administraciones de infraestructura vial en CDMX suelen basar su presupuesto en mantenimiento reactivo (reparar cuando ya falló). Este modelo permite transicionar a un mantenimiento proactivo calculando la Vida Útil Remanente (RUL) y demostrando el Retorno de Inversión (ROI) de materiales inteligentes.
Stack Tecnológico Lenguaje: Python 3.x. Librerías: Pandas, NumPy, Matplotlib (Análisis y Visualización). Machine Learning: Scikit-learn (Random Forest Regressor). Database: SQLite3 (Simulación de inventario vial).
Aviso de Datos: Este proyecto utiliza Data Sintética (Synthetic Data Generation) basada en rangos físicos reales de ingeniería civil. Se optó por esta metodología para demostrar la arquitectura de la solución manteniendo la confidencialidad de datos gubernamentales, permitiendo a su vez simular escenarios extremos de estrés hídrico y térmico.
Conclusiones Clave: Resiliencia: El uso de aditivos de auto-reparación reduce la tasa de degradación en un 40% en condiciones de alta pluviosidad. Optimización Financiera: Aunque el costo inicial es superior, el punto de equilibrio (Break-even point) se alcanza en el año 4, reduciendo el gasto operativo total en un 25% a 10 años.
